This checklist is for the APK20020 test update containing subtitle outline color (#475) and the global collection view (#362). A download link is added only after the exact build and artifact checks pass.

1. Install the APK over **Nuvio TV/Mobile Test** using **Update**. Open the app and confirm that your existing accounts, profiles and settings remain available. Do not uninstall the existing app.
2. Play a video with plain-text SRT/VTT subtitles. Open **Subtitles → Style**, set **Edge** to **Outline**, then open **Outline color**. Choose White, Red and Blue: the outline should change immediately while your selected text color remains unchanged. Close and reopen Style, then restart the app: the selected outline color should persist.
3. In Style, set **Background** to **Dark 25%** and change **Opacity**. The background should retain its existing black color and opacity. With **Background → None** and **Edge → Shadow**, the chosen outline color should color the shadow. Choose **Restore default**: the outline should return to pure black. A second plain-text subtitle should follow the shared outline color while retaining its existing separate style overrides. An authored ASS track should retain its file-defined colors and show **Kept from the ASS file**.
4. Open **Settings → Home screen → Collections → Default collection view**. All eight choices should be reachable: **Automatic, Grid, Timeline, Ranking, Saga, Decades, Mural, Showcase**. Choose **Showcase**, confirming when using the remote; reopen Settings and check that it remains selected. Highlight another choice and use **Cancel**: the saved choice should remain unchanged.
5. Open a collection whose **Display** control shows **Default**. It should use Showcase. Choose a different view with that collection’s **Display** control and reopen it: the explicit choice should win. Cycle Display back to **Default**, then change the global setting to Timeline: that collection should inherit Timeline, while a different collection with an explicit view keeps its own choice. Merely opening a collection must not create an override.
6. Set **Default collection view → Automatic**. An ordinary collection should use its existing Grid view and a Directors collection its existing Timeline view. Open a single catalog using **See all**: its existing behavior should remain unchanged, including with the global setting set to Showcase.
7. Give profile A Showcase and profile B Grid, then switch A → B → A and restart the app. Each profile should retain its own default and collection overrides. A new profile should start with Automatic. Existing provider Shared/Separate choices must remain unchanged.
8. On a phone, test portrait and landscape at **Interface size → 150%**. The collection Display control and all eight global choices should remain reachable, and the first title should still open normally. In the subtitle Style panel, all six color swatches, all seven font choices, Outline color and Restore default should be visible and selectable. With a TV remote, all controls should remain reachable through their existing navigation and confirmation controls.
9. Play a short segment, use the existing Reload control once, and resume playback. The accepted player controls, synopsis reader, source filters and Cached behavior should remain available with their prior settings. No provider failure simulation or account removal is needed.
