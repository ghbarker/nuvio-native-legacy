# Existing subtitle-outline contracts

`run.py --source ABS --output FRESH_ABS --cc CC --platform tv|mobile [--sanitize] [--private] [--group all|player|secondary|ass|geometry]`

The copied assertion fixtures are byte-identical to the independently approved #475 fixtures. This producer selects source/compiler/platform, uses Linux gc-sections or Darwin dead-strip, records actual compile dependencies and logs, and supplies only the typed fixed clock needed by private diagnostics. Style keyboard/palette callbacks are the separate `../subtitle-style` producer; `geometry` runs the accepted complete Style body, real layout and SDL pointer fixtures.

The focused CI job should run on Linux with `pkg-config` and `libass-dev` installed. The default ASS producer uses that actual installed SDK/library pair and records its package version, header/shared-library hashes and bundled-font hash. `--libass-reference-runtime ABS_LIBASS` is an explicit local preflight adapter only: it requires the actual runtime API to report exactly0.17.3 before using the unchanged, pinned0.17.3 public headers from the original approved fixture. It does not silently replace a missing CI development package.

The checks execute complete actual C modules, real preference file I/O, real layout/pointer events, and real libass software frames. Typed finite text/GFX boundaries do not certify GPU output, actual glyph appearance, a physical phone or a native platform decoder. Normal/ASan are selected by the caller; the root plan supplies exact source pins later. Outputs must go outside the staged recipe, under the review/output tree.
