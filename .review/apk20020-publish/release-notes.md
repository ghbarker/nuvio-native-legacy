Logs10 adds subtitle outline colors and a default view for collections. It updates Nuvio TV/Mobile Test in place using the same package and signing certificate; accounts and settings stay in place.

- Choose **Outline color** in **Subtitles → Style**. Plain-text primary and secondary subtitles share the chosen outline/shadow color. Authored ASS subtitles keep their file-defined styling; native platform subtitles and bitmap tracks keep their existing support.
- Choose among all eight views in **Settings → Home screen → Collections → Default collection view**. Each profile keeps its own default. A collection's explicit Display choice still takes priority; choosing Default makes it inherit the profile's setting again. Automatic keeps the existing view-selection behavior, and See all for a single catalog keeps its existing behavior.

Version: **2.0.20-test-logs10 (20020)**.
