1. Install this update over **Nuvio TV/Mobile Test**. The package and signing certificate match the existing test app, so its accounts and settings stay in place.
2. Open a series with **Play the next episode automatically** switched Off. Show the playback controls and use **Next episode**, then **Previous episode**. On a remote, move Right from Play to Next; move Left from Play to Previous.
3. Check an available first and last episode: Previous is disabled at the beginning, Next at the end. The buttons follow the available catalog episodes across season boundaries.
4. During a movie or episode, press **Reload**. Check that the same source returns to its position and keeps audio/subtitle choices. Repeat while paused to check that playback remains paused.
5. Open **Settings → Appearance → Synopsis text size → Large** or **Extra large**, then select **Confirm**. Leave and reopen the row to check that the choice stayed saved. Check a title description and an episode description; menus and subtitle size keep their own settings.
6. On a title, open **More options → Read synopsis**. Scroll through a long description, then use **Close** or Back. You should return to the previous page. The reader shows the description supplied by the catalog.
7. Open **Sources** and select **Cached**. Only sources explicitly reported as cached remain. Unknown cache metadata does not count as cached.

This update contains the player controls, synopsis sizing/readers and stricter cache indicators. Issues #475 and #362 are reserved for a later test update.
