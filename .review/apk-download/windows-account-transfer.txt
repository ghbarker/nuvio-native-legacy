Nuvio TV/Mobile Test: preserve your accounts once, then use normal APK updates

The installed test APK was signed with a temporary key that was not retained.
Android cannot accept the fixed APK as an update to that particular build.
This helper backs up your account data and original installed APK locally,
verifies every file, and restores the data to the consistently signed test APK.
You should not have to enter accounts again.
Nothing from the backup is uploaded. Keep the backup folder private.

1. Download and save the helper to your Windows computer:
   https://github.com/ghbarker/nuvio-native-legacy/releases/download/tv-mobile-test-languages-481/Nuvio-Test-Accounts-v2.ps1

   The fixed APK (the helper downloads it for you):
   https://github.com/ghbarker/nuvio-native-legacy/releases/download/tv-mobile-test-languages-481/Nuvio-TV-Mobile-Test.apk
2. Enable USB debugging on your phone/TV, connect it by USB, and accept its
   "Allow USB debugging" prompt. Connect only that device.
3. Open Windows PowerShell in the folder containing the helper and run:

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Nuvio-Test-Accounts-v2.ps1

   This only creates and verifies a backup. It does not uninstall anything.
   It stops the app briefly to get a consistent snapshot. You can reopen it.
   Administrator privileges are not required. The helper sets and verifies
   only the local backup folder's access permissions, without audit or owner changes.
   The helper uses an existing adb.exe, or downloads Google's official tools
   into %LOCALAPPDATA%\Nuvio-Test-Account-Transfer. Windows system files stay unchanged.

4. When ready for the one-time transfer, run:

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Nuvio-Test-Accounts-v2.ps1 -Transfer

   It makes a fresh verified backup, downloads and checks the fixed APK, and
   tries an in-place update first. If Android rejects the old signature, it asks
   you to type UPDATE. Only that confirmation permits the one-time reinstall.
   Do not disconnect the device or open the app during the transfer.
   The helper restores and verifies every file before opening the app.

If interrupted after the reinstall, keep the backup folder shown by the helper
and use this recovery command, substituting that exact folder:

   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Nuvio-Test-Accounts-v2.ps1 -Restore -BackupFolder 'C:\Users\YOURNAME\AppData\Local\Nuvio-Test-Account-Transfer\backup-...'

Recovery asks you to type RESTORE before replacing the app's saved data with
the verified backup (and reinstalling the selected APK if its signature differs).
Any existing native app data is backed up first. To return to the original app
instead of the fixed APK, add -OriginalApk to the recovery command. That uses
the original installed APK saved alongside your backup; no old signing key is needed.
The original backup is always kept. If a command fails, stop and share only the
short error message; do not send the backup or manifest.

After your accounts work, future test APKs using the stable signing key can be
downloaded and installed with Android's usual Update button.
