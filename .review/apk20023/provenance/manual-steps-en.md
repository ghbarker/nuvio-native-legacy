1. Open **Settings → Languages and subtitles**. Under **Main subtitle** and **Second subtitle**, check that both offer Size, Subtitle font, Color, Opacity, Background, Position, Border, Outline color, Bold, Delay and Restore default. The second subtitle also retains **Second subtitle position** (At the top / Stacked with the main).
2. Change **Main subtitle → Size** to **150%**, choose **Confirm**, then reopen Settings. The value should remain 150%. Change it again and choose **Cancel**; 150% should remain. Repeat with a second-subtitle appearance choice.
3. Play a title with a main and a second text subtitle. Set different fonts, text colors, outline colors, opacity and bold for each. Each subtitle should use its own choices. **Same as main** should follow the main style for that field.
4. Set **Second subtitle → Position** to a numbered position. It should move independently of the main subtitle. Choose **Second subtitle position → At the top** or **Stacked with the main**; that existing placement should take over again.
5. Change **Second subtitle → Delay**, then open the second subtitle’s in-player delay control. Both should show the same saved manual delay. Change it there and reopen Settings; the new value should match. The manual delay should survive reopening playback; automatic synchronization remains session-specific.
6. Choose **Restore default** in each section. Main subtitle styling should return to the existing default. Second subtitle overrides should return to inheritance/automatic placement and manual Delay 0. Existing account, addon and playback preferences should remain intact.

7. Open a multi-source collection while its addons are still becoming available. Ready rows should load in sequence; a missing or empty addon should not prevent later ready rows from loading. Scroll vertically and horizontally while rows arrive; your position should remain.
8. Open titles whose metadata addon uses long artwork URLs. Available fallback artwork should load. This checks the bounded registry fix; it does not establish that every random blank poster reported earlier is resolved.
9. Confirm the existing playback, collection view, Cached filter, source filters and synopsis size options remain available. Install this build as an update; do not uninstall or clear app data.
