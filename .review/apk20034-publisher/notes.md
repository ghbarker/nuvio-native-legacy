Logs24 is a private test build for the Bigg Boss search-window fix. It retains the existing season/episode diagnostics, playback features and TV/Mobile support.

Install over Nuvio TV/Mobile Test using **Update** to keep accounts and settings. The package and signing key must match the existing test app.

1. Search for Bigg Boss with the same addons and profile you used before.
2. Check that the matching series appears in the results, then open it and check its seasons and episodes.
3. If results or episode rows are missing, download a fresh log after reproducing the problem.

The validation asset binds this APK to its exact private source and fresh Android ARM32/ARM64 build checks. Earlier build results do not count as fresh. This publication makes no public PR or upstream fix claim, and includes no fresh macOS, emulator or physical-device result.

Existing diagnostic records remain bounded to title/source hashes and layout state, with at most 32 changed records per opening and a 250ms sampling interval.
